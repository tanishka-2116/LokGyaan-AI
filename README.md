# LokGyaan AI

## Overview
LokGyaan AI is an AI-powered platform designed to capture India’s oral traditional knowledge in regional languages and convert it into structured, usable digital knowledge for social good.

## Problem
Traditional knowledge is mostly shared orally and is rapidly disappearing due to lack of documentation and generational gaps.

## Solution
The platform uses speech-to-text and NLP techniques to understand spoken knowledge and organize it into structured formats like datasets and knowledge graphs.

## Technology Stack
- Python
- FastAPI
- Multilingual Speech-to-Text
- NLP
- Knowledge Graphs
- Cloud Deployment
